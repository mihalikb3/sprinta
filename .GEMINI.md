This is a personal project: I want to build a command-line based tool that is an AI-running coach, similar to Runna. I want it to automatically sync to garmin through garminconnect. I want the command-line interface to be fancy, kind of like the gemini cli: colours, nice visualisations, etc. I want there to be an AI-based recommendation system, that recommends workout using scientific principles, maybe from a folder where I upload relevant research papers? I want the user to be able to set things like: how much they train per week, which days they train, do they want to do weights based work, which race are they training for, etc.
